# Raised Bed Soil Calculator & Formulation Guide

An open-source horticultural calculator to compute cubic yardage and exact volumetric proportions for high-yield raised vegetable beds.

## Standard Tested Formulation
* **60% Quality Screened Topsoil**: Provides mineral structure, moisture retention, and clay-silt anchor.
* **30% Bio-Active Organic Compost**: Supplies microbial biodiversity, fungal mycelium, and slow-release nitrogen.
* **10% Aeration Mineral (Perlite / Coarse Sand)**: Prevents root compaction and promotes rapid capillary drainage.

Detailed DIY soil mixing recipes and soil amendments can be referenced in the official [Raised Bed Soil Mix Ratios Guide on The Blog Daily](https://theblogdaily.com/raised-bed-soil/).
